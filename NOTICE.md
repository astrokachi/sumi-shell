# Notices

## Omarchy

Several parts of Sumi began as copies of [Omarchy](https://github.com/omacom/omarchy)
and were then restyled and changed. Omarchy is released under the MIT licence; see
its `LICENSE` file in that repository for the full text and copyright notice.

| Sumi | Started from |
|---|---|
| `plugins/sumi.menu` | `omarchy.menu` |
| `plugins/sumi.osd` | `omarchy.osd` |
| `plugins/sumi.notifications` | `omarchy.notifications` |
| `plugins/sumi.lock` | `omarchy.lock` |
| `plugins/sumi.image-picker` | `omarchy.image-picker` |
| `bin/sumi-keybindings` | `omarchy-menu-keybindings` |

The rest (`sumi.notch`, `sumi.battery-saver`, `hypr/sumi.lua`, the theme and
the scripts) is Sumi's own.
